# Reels — Romário x Ancelotti (@camisa10gyn)

- `out/reels.mp4` — vídeo final, 1080×1920, 30 fps, 50,6 s.
- `index.html` — animação (CSS, tempos sincronizados com a narração).
- `render.js` — renderiza quadro a quadro com Playwright + ffmpeg: `node render.js`.
- `music.py` — gera a trilha de fundo sintetizada (`audio/trilha.wav`).
- `audio/voz.mp3` — narração (voz "Diego", pt-BR). `audio/mix.wav` — voz + trilha.
